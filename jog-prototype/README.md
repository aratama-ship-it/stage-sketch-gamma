# 転換中の「小走り」試作

舞台スケッチγの**ローカル試作**です。正式な反映先は舞台スケッチγの更新であり、β版の更新には含めません。公開・配信はまだ行っていません。演者を選択して「このシーンへの移動」を「歩く／小走り」に切り替えます。既定は歩行。選択はそのシーンの演者の駒に保存され、直前のシーンからその駒へ移る転換、袖からの入りに適用します。袖へのはけは出発シーンの駒の選択を使います。小走りを選んでも約2m未満の移動、移動のない駒、保存姿勢が「歩く」の駒は従来の歩行処理へ戻します。台上・器具上や持ち物がある姿勢、暗転の処理は従来のままです。

## 確認手順

`python3 -m http.server 18764 --bind 127.0.0.1` を作業木で実行し、`http://127.0.0.1:18764/stage.html` を開きます。「ショー一覧」→「テスト: 全機能の試験場」→ A-4「立ち姿・歩き始め」→「次のシーン」。A-5へ6秒で転換します。演者01は曲線の小走り、03は直線の小走り、02は短い歩行、07はその場で停止します。A-5で演者を選ぶと「このシーンへの移動」を切り替えられます。正面図と3Dで見ることができます。統合試験場のIDは生成器とJSONの双方で `gamma-feature-test-v26` です。

## 元動作とモデル

[CMU Graphics Lab Motion Capture Database](https://mocap.cs.cmu.edu/) の [Subject 35, trial 23](https://mocap.cs.cmu.edu/search.php?subjectnumber=35) の `run/jog` を基準にしました。120fpsの `35_23.amc` のフレーム49〜137（1始まり）から一歩ずつ左右交互の約0.73秒の周期を抽出し、2フレームおき45姿勢を `stage-jog-reference.js` に格納しています。ASFの長さは [公式FAQ](https://mocap.cs.cmu.edu/faqs.php) に従い `(1/0.45)*2.54/100` 倍でmへ変換し、約1.75mの被写体身長で正規化しました。反対側の走行 `35_24.amc` でも速度と上下動を確認しました。原データでは重心の進行が約3.4m/s、左右の接地間隔が約0.37秒です。小走り試作では**速度目安を1.9m/s、ステップ長を身長の約44%**へ落とし、腕・体幹の周期は参照動作をリタイミングしています。人体そのものの関節位置は参照モーションに依拠し、足は動線上に着地点を置いて接地中に固定し、膝を2骨IKで解きます。開始・終了は保存済みの姿勢に滑らかにつなぎます。

表示時の腕は、参照周期の肩の前後振幅を左右それぞれ計10度（両端約5度ずつ）縮め、肘の内角を10度開いています。上腕・前腕の長さと曲がる平面は保ち、計測元45姿勢、足の接地と膝の処理は変更しません。A-4→A-5の小走り中に検証した肩の振幅は左32.9→22.9度、右36.7→26.7度です。

ASF/AMCの回転順は[Acclaim形式の解説](https://research.cs.wisc.edu/graphics/Courses/cs-838-1999/Jeff/ASF-AMC.html)に従い、列ベクトル計算ではXYZを左から順に作用させています。試作初版では行列を逆順に合成し、肘が前・手首が後ろの不自然な腕になっていました。変換を修正し、参照周期の全45姿勢とA-4→A-5の補間全区間で、腕の前後関係・骨長・連続性を検査します。

抽出器 `extract_cmu_jog.py` は参照ファイルが `gamma-dev/jog-transition-prototype/reference/35.asf` と `35_23.amc` にある場合に `stage-jog-reference.js` を再生成します。参照元SHA-256: `35.asf` = `2a8e2eda3c0d7d828566b2a9a8ab36b2b8b3864110574e8b73c8f069fded416c`、`35_23.amc` = `9a7e75286fa965cecd207784af21273e816131fbae18e267077729250093a832`。動画 `35_23.mpg` はローカル比較用で製品に読み込みません。

CMU指定の謝辞: “The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217.” CMUはデータの利用を無償で認めていますが、元データや変換データそのものの販売は認めていません。

統合候補の試験場IDは `gamma-feature-test-v26` です。A-4→A-5では演者01と03が小走りです。この段階で確認したのはソース動画との目視、局所的な関節軌道、接地・連続性の自動テストと試験場のブラウザ再生です。複数の被験者、低速域、実際の舞台での足運びやパフォーマンスを測定した検証ではありません。ベータには反映していません。
