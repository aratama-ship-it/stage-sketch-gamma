Mac版を新しい舞台へ入れ替える

新しいアプリをダウンロードし、いま使っている「舞台スケッチγ.app」と置き換えます。

ダウンロード（GitHub Releases）

導入手順

  1. GitHub Releasesから最新のzipをダウンロードします。
  2. zipを解凍します。
  3. いまの「舞台スケッチγ.app」を、新しいアプリで置き換えます。置き場所は「アプリケーション」またはデスクトップです。
  4. 初回だけ、アプリを右クリックして「開く」を選びます。

保存データについて

アプリ本体を置き換えても、ショーの保存データはアプリとは別のWebView保存領域に残ります。同じ舞台スケッチγ Mac版として更新するかぎり、置き換えだけで保存領域は削除されません。
