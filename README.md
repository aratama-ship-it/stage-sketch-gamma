# 舞台スケッチ ガンマ

舞台スケッチの独立開発版です。既存GitHub版の公開コミット `44e259079b0df411a4fda58290d5840bc4d95f70` を土台に、照明の配置・デザインをショーへ組み込みました。

## 開く

[舞台スケッチ ガンマ](https://aratama-ship-it.github.io/stage-sketch-gamma/stage.html)

通常モード・3Dモード・配置モード・照明デザインモードを上部で切り替えます。新しい照明は「照明デザインモード」で見え方を確認し、「ショーへ適用」でショーに保存します。「保存」は照明だけの控え・ファイル書き出しです。

## 初版 γ0.1.0 の範囲

- 既存の舞台編集・音楽・タイムライン・3Dのコードを継承。
- 照明の2モードは一つの編集画面を共有。タブ切替時に編集内容を保持。
- ショーの場面IDと照明キューを照合。人物・舞台セットを照明ファイルで上書きしません。
- 照明をショーのJSONに同梱。未適用の照明はガンマ専用の編集控えへ保存。
- 旧版とlocalStorage・音源IndexedDB・PWAキャッシュを分離。

新しい照明の**通常・3D・共有画面での再現は次段階**です。現在の通常画面と3D画面は従来の照明を表示します。新しい照明のレーザー・カッター・LX cueを異なる旧描画へ誤変換しないためです。

GitHub Pagesは静的公開先です。会議用のリアルタイム共有と演者リンクには元のWorker APIが必要であり、ガンマ専用バックエンドは接続していません。元のβサービスをこのリポジトリから更新しません。

## 保存済みのショーを使う

旧版でショーを書き出し、ガンマへ読み込んでください。音源を含まないJSONでは音源ファイルの再接続が必要です。旧版のブラウザ保存を自動移行しません。
ガンマの新しい照明情報を含むショーはガンマで開いてください。旧版はこの追加情報を解釈しません。

## ローカルで開く

```sh
python3 -m http.server 8961 --bind 127.0.0.1
```

`http://127.0.0.1:8961/stage.html` を開きます。

Safari実機でのPWAオフライン起動、音楽の実機出音・長時間同期は引き続き確認が必要です。
