# デザイントークンシート — 舞台スケッチγ・ツール列の照明トグル

- 更新日: 2026-09-22
- 対象: 舞台画面左列と3D画面内の「照明効果」「作業灯」のSVGアイコンとトグル。既存トークンを再利用し、画面全体の再設計はしない。
- 意図: 舞台で光の見え方を試す二つの操作を、他の道具と同じ線画・押下状態で見分ける。

| 用途 | 既存トークン・値 | 適用 |
|---|---|---|
| 操作帯の背景 | `--desk: #191512` | `.stage-center-bar` |
| 通常のアイコン | `--milk-dim: rgba(240, 231, 214, .55)` | 背景上の合成色 `#8f897e`、5.23:1 |
| 選択中のアイコン | `--paper: #efe7d6` | 選択背景上で11.51:1 |
| アイコンの描画 | `currentColor`、線幅1.3、viewBox 16×16 | 既存の移動・矢印アイコンに合わせる |
| アイコン寸法 | 15×15px | `.stage-tool-icon svg` |
| ボタン寸法 | 幅28px、最小高さ30px | `.stage-tool-grid button.is-icon` |
| グループ間隔 | 4px | `.stage-tool-split` |
| 形状・動き | 既存の角・枠・hover・focus・押下状態を再利用 | 新規の角丸・影・モーションなし |
| 3D内の操作 | 既存の `.stage-fpv-chip`、アイコン15px、最小高さ34px、間隔5px | 既存のフローティング操作群の先頭 |

通常色のコントラストは `tools/contrast.mjs '#8f897e' '#191512'`、選択色は同ツールで `'#efe7d6' '#402417'` を測定（2026-09-22）。SVGの意味は形だけに頼らず、ボタンのアクセシブル名と押下状態、既存の説明表示でも伝える。

## 舞台画面の固定ヘッダーと独立スクロール（2026-09-25）

| 用途 | 値 | 適用 |
|---|---|---|
| ヘッダーの背景 | 既存の `--desk` | スクロールする内容がヘッダー越しに透けない |
| ヘッダーの前面順 | 30 | 3列の内容より前面に表示する |
| 操作群を2行へ折り返す幅 | 1500px以下 | 1280pxで操作群が細く縮みヘッダーが約465pxに伸びるのを防ぐ |
| 折り返した行間 | 既存の `--gamma-gap`（8px） | ヘッダー内の操作群 |
| 3列独立スクロールの下限幅 | 1120px | 既存の縦1列レイアウトとの境界に揃える |
| 舞台画面の高さ | `100dvh` | タイムライン用の既存下余白を引いた残りを3列に割り当てる |
| 3列のスクロール | 各列 `overflow-y: auto`、格子行 `minmax(0, 1fr)` | 列を動かしても別の列とヘッダーは動かない |
| スクロールバー | 既存の `--line-dark`、細幅 | 明るい標準バーが暗い作業面で目立ちすぎないようにする |
| 左右の横はみ出し | 非表示 | 列全体に不要な横スクロールバーを出さない |
| タブ切り替え時の画面位置 | 先頭 | 劇場設定などの高さ計算が前タブのスクロール位置で変わらないようにする |

配色・文字・ボタン寸法は変更しない。狭い画面の縦1列、iPad PWA、スマホ閲覧の既存レイアウトは維持する。

## 劇場設定・バックスクリーンの長さ編集（2026-09-28）

| 用途 | 値 | 適用 |
|---|---|---|
| 選択中のスクリーン | 既存の `--brass: #9c823f`、線幅 5px | 平面図の選択状態。未選択は従来の `#e9e8df` |
| 端点の掴み位置 | 既存の 8×8px 描画、マウス判定は半径 13px、タッチ判定は半径 22px | タッチの直径 44px を確保する |
| 長さ欄 | 既存の `.stage-venue-editor-setting`、2列 92px / 残り、間隔 8px、11px。入力高 44px | 選択時のみ表示し、タッチで扱える高さにする |
| 配置操作と編集操作の間隔 | 既存の `.stage-tool-grid` 6px、編集欄の上 8px | 新しい装飾・モーションなし |

表示中の平面図グリッドを長さ単位に使う。ズーム変更だけでは保存済みの座標を動かさず、配置または長さ編集時に吸着する。文字サイズ・入力の基本スタイルは既存の劇場設定を継承する。新規スクリーンの初期色はグレー `#777777`。選択時の3色ボタンは既存の床色ボタンに合わせ、黒 `#303030`、白 `#e9e8df` を選べる。色指定のない旧保存は従来の白で描く。
